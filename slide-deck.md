Simply summing raw scores lets lexical outliers drown out semantic matches (or vice versa). Fusion normalizes both signals.A. Reciprocal Rank Fusion (RRF) — Core Hybrid Pattern:Ignores raw score magnitudes completely; merges results using rank positions:RRF_Score(d) = Σ 1 / ( k + rank_i(d) ) [typically k = 60]Scale-invariant: No min-max normalization required across disparate engines.Consensus reward: Documents appearing in top ranks of both keyword and vector lists receive an exponential boost.Noise dampening: Constant k prevents rank #1 outlier dominance.B. Our Drupal 11 Implementation: Score Boosting:Implemented via Search API processor: database_boost_by_ai_search1. Base Query: search_api_db executes full-text + facets + boolean filters.2. Vector Lookup: Queries content_vectors (pgvector) for semantic neighbors.3. Hybrid Merge: Injects weighted cosine similarity boost into SQL score.Why it excels in Drupal: Preserves native SQL facet counts, pagination, and Views access checks; type-aware boosting via pass_conditions_fields;
